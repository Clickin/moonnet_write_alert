# TYPE-MOON 글쓰기 이탈 경고

TYPE-MOON 게시글 작성/수정 화면에서 실수로 페이지를 벗어나는 것을 막기 위한 사용자 스크립트입니다.

## 기능

- `www.typemoon.net` 페이지에서 SmartEditor2 작성 iframe을 감지합니다.
- 작성 iframe이 있는 동안 브라우저 기본 페이지 이탈 확인창을 활성화합니다.
- 새로고침, 탭 닫기, 뒤로가기, 앞으로가기, 링크 이동, 폼 제출 같은 일반적인 페이지 이동에 적용됩니다.
- 글 작성 완료 저장 요청은 정상 저장으로 보고 이탈 확인창을 띄우지 않습니다.
- 작성 iframe이 사라지면 이탈 확인도 비활성화됩니다.

## 설치

1. Tampermonkey, Violentmonkey, Greasemonkey 같은 사용자 스크립트 관리 확장을 설치합니다.
2. 이 페이지의 설치 버튼을 눌러 스크립트를 설치합니다.
3. `www.typemoon.net`에서 게시글 작성 또는 수정 화면을 엽니다.

## 사용법

별도 설정은 없습니다. 작성 화면에 들어가면 자동으로 동작합니다.

작성 중 페이지를 벗어나려고 하면 브라우저가 기본 이탈 확인창을 표시합니다. 계속 이동하려면 확인을 선택하고, 작성 화면에 남으려면 취소를 선택하면 됩니다.

## 주의사항

- 최신 브라우저는 보안 정책상 이탈 확인창의 문구를 스크립트가 직접 지정하지 못하게 제한합니다.
- 브라우저에 따라 사용자가 페이지와 한 번 이상 상호작용한 뒤에만 이탈 확인창이 표시될 수 있습니다.
- 이 스크립트는 글 내용을 저장하거나 외부로 전송하지 않습니다.
- 외부 라이브러리나 원격 코드를 불러오지 않습니다.

## 적용 대상

- `https://www.typemoon.net/*`
- `http://www.typemoon.net/*`

작성 화면 감지 조건:

```html
<iframe src="https://www.typemoon.net/plugin/editor/smarteditor2/SmartEditor2Skin.html">
```

## 문제 제보

동작하지 않는 작성 페이지가 있으면 해당 페이지 주소와 사용 중인 브라우저, 사용자 스크립트 관리 확장 이름을 함께 알려주세요.
